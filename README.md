# RAG Learning Wiki

這份專案以五篇正式學術論文建立RAG(檢索增強生成)初學者Wiki，並製作14頁互動式HTML教學簡報

## 開啟簡報

直接用瀏覽器開啟`slides/index.html`即可，不需要安裝套件或啟動伺服器

支援上一頁、下一頁、鍵盤切換、頁面目錄、RAG兩階段示意、Top-k候選比較、文件切分、索引更新和六步教學案例

## 專案目錄

- `AGENTS.md`：專案規範與九項需求
- `requirements/`：需求摘要與目前成果對照
- `raw/`：五篇原始論文PDF
- `wiki/`：六篇教學條目、五篇來源紀錄與ID索引
- `workflow/graph.md`：Graph設計與局部返回規則
- `workflow/evidence-cards-v2/`：現行12張可追溯證據卡
- `workflow/drafts/`：現行教學大綱v2及逐頁稿v3
- `slides/`：完整HTML簡報與SVG捲軸資產
