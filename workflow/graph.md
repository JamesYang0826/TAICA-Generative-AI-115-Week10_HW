# RAG Learning Wiki工作流程

## 節點順序

N01接收論文 → N02逐篇驗證 → N03整理Wiki → N04檢查覆蓋與追溯 → N05規劃逐頁稿 → N06獨立內容審查 → N07產生HTML → N08功能與版面測試

## 返回規則

- N02來源不符：退回該篇重新核對，不重做其他來源
- N04知識或追溯不足：返回N03，若來源不足則返回N01／N02
- N06發現教學或內容問題：返回N05；若Wiki原文主張有誤，再返回N03
- N08發現互動或排版錯誤：返回N07，只修正呈現層，不任意改寫學術內容
- 同一問題最多修正三輪，無法解決時標記`BLOCKED`並記錄原因

## 提前檢查的設計

- N02先確認正式書目、PDF及論文主張
- N04確認Wiki ID、來源ID、證據卡及頁面映射
- N05在送審前檢查可見教學案例、首次術語解釋、APA7書目、跨頁數值與模型適用條件
- N06獨立確認主張忠實度及初學者可理解性
- N08檢查HTML互動、鍵盤導覽、手機與桌面呈現

本檔案是現行Graph規格，不是歷次執行結果。實際執行與修正紀錄請參閱另外保存的精簡更新歷程報告。
